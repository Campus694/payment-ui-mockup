# Payment UI — Design Mockup

Демо-макет мобильного интерфейса оплаты: тёмная тема, выбор метода, экран реквизитов, слайдер подтверждения, квадратное предупреждение с обратным отсчётом и переключение языка RU/EN.

> ⚠️ **Это только дизайн.** Страница не принимает и не проверяет платежи. Все реквизиты, суммы, названия банка и магазина — вымышленные плейсхолдеры (`Демо-Банк`, `0000 0000 0000 0000`, `Demo Store`).

## Что внутри

- Один статический файл `index.html` — без зависимостей и сборки (шрифт Roboto грузится с Google Fonts).
- Чистый ванильный JS: i18n-словарь, генерация ID заказа, копирование в буфер, drag-слайдер на Pointer Events, состояние в `localStorage`.
- Иконки и логотип — инлайновые SVG.

## Запуск

Просто откройте `index.html` в браузере — или опубликуйте как статический сайт (GitHub Pages, Cloudflare Pages и т.п.).

## Структура экранов

1. **Выбор метода** — сумма, комиссия, карточка метода.
2. **Предупреждение** — модальный квадрат с 3-секундным отсчётом.
3. **Реквизиты** — демо-данные с кнопками копирования.
4. **Подтверждение** — bottom-sheet со слайдером.
5. **Обработка** — демо-состояние ожидания (без реальной проверки).
