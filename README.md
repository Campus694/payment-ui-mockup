# ParityPay — Payment Checkout UI

Тёмный мобильный интерфейс оплаты: выбор метода, экран реквизитов, слайдер подтверждения, предупреждение с обратным отсчётом, переключение языка RU/EN.

Один статический файл `index.html` — без зависимостей и сборки (шрифт Roboto грузится с Google Fonts). Чистый ванильный JS: i18n-словарь, генерация ID заказа, копирование в буфер, drag-слайдер на Pointer Events, состояние в `localStorage`. Иконки и логотип — инлайновые SVG.

## Запуск

Откройте `index.html` в браузере — или опубликуйте как статический сайт (GitHub Pages, Cloudflare Pages и т.п.).

## Экраны

1. **Выбор метода** — сумма, комиссия, карточка метода.
2. **Предупреждение** — модальный квадрат с 3-секундным отсчётом.
3. **Реквизиты** — данные перевода с кнопками копирования.
4. **Подтверждение** — bottom-sheet со слайдером.
5. **Обработка** — состояние ожидания.
